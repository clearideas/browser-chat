Browser Chat – development

Local pages for the Clear Ideas® chat widget and its test server.

Status

  • Widget bundle (dist/)
  • Test server on

npm run dev keeps both up to date: it rebuilds the widget on every change and runs the test server, which returns canned replies and never calls an AI service.

Try the widget

  • Demo site – a normal configuration, with controls for language, position and dark mode
  • Adversarial site – hostile configuration; its markup must appear as plain text and never run
  • Disabled site – chat switched off: the server refuses the widget, so the launcher is hidden
  • Voice site – realtime voice over the test server's WebSocket relay, and recorded voice (needs a microphone)
  • Recorded voice site – recorded voice only, so the microphone records a message

In the chat, send any message to have it echoed back, or /fixture help for the reply scenarios: Markdown, citations, errors, dropped connections, stream formats and hostile content.

Browser test pages

Used by npm run test:e2e, and usable by hand: each page says what it checks and what you should see.

  • Languages – the widget follows the page language, with regional fallbacks, right-to-left layout and custom strings
  • Hidden launcher – a site that opens the chat from its own button; the hidden launcher must not block clicks on the page
  • Style isolation – hostile page CSS that must not change the widget
  • Strict Content-Security-Policy – no inline scripts or styles allowed
