Languages

The widget is initialized here without a locale option, so it follows the page's <html lang>, and the browser's languages when the page has none. Regional tags use their language (fr-CA → French, pt-BR → Portuguese), Chinese is matched by script (zh-TW → Traditional), and languages without a translation fall back to English. The test server answers in the same language.

Expected: changing the page language below changes the launcher label and the open chat at once, including the server's greeting. Arabic lays the panel out right to left. “Add Swedish strings” supplies a custom translation with setMessages(), so sv is no longer English.
