Hidden launcher

Some sites hide the floating launcher (fabHide: true or widget.hide()) and open the chat from their own button instead. The widget keeps an invisible box in the page corner, where the launcher sits when shown.

Expected: while the launcher is hidden, that box lets clicks through: the striped page button in the corner counts every click, including right where the launcher would be. “Open chat” below opens the widget. With the launcher shown, it covers part of the corner button as usual.
