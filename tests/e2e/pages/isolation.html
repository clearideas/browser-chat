Style isolation

This page's CSS is hostile: a 5px root font size, Comic Sans in magenta, uppercase text, red borders and yellow backgrounds on every div, p, button and link, and rules that hide anything whose class starts with ci-widget. It also contains two page elements that reuse the widget's class names (hidden by those same rules; the tests check that the widget's CSS leaves them alone).
Expected: the widget in the corner looks exactly as on the demo page: none of the page's CSS reaches it, because it renders in a shadow root, and its wrapper elements take no space in the page (no red border line). The widget's own CSS does not style the page either.
